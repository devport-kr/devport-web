## 매일 새로 쏟아지는 AI 프로젝트

유튜브, 뉴스레터, GitHub, Reddit, Hacker News 등 여러 플랫폼을 돌아다니며 직접 확인해야 했던 기술 소식을 하나의 공간에서 확인할 수 있습니다. 영어 중심의 개발 생태계에서 핵심을 빠르게 파악할 수 있도록 한국어 기반으로 재제공합니다.

## 단순 요약이 아니라 맥락을 전달합니다
https://cdn-images-1.medium.com/max/1600/0*dDezHZhZUGlMow5t.png
devport는 기술 트렌드를 "이런 게 나왔다" 수준에서 끝내지 않습니다. 왜 이 기술이 등장했는지, 어디에 쓰이는지, 기존 대안과 뭐가 다른지까지 재구성해서 전달합니다. 트렌드를 보는 것에서 끝나는 게 아니라, 내 기술 스택에 어떻게 연결할 수 있는지 판단할 수 있는 근거를 제공하는 것이 목표입니다.

## Ports: 리포지토리를 살아있는 지식으로 변환
https://cdn-images-1.medium.com/max/1600/0*M7cAOlD8-ueL7KRZ.png

복잡한 GitHub README만으로는 프로젝트의 목적과 구조를 쉽게 파악하기가 어렵습니다.

- **프로젝트 위키:** 구조, 목적, 릴리스 흐름을 한국어로 일목요연하게 정리하여 제공합니다.
- **AI 챗봇:** 정리된 내용을 바탕으로 궁금한 점을 즉시 묻고 답을 얻을 수 있는 채팅 기능을 지원합니다. 문서를 일일이 뒤질 필요 없이 필요한 정보만 빠르게 추출할 수 있습니다.

## LLM Ranking: 데이터 기반의 모델 선택 가이드
https://cdn-images-1.medium.com/max/1600/0*4hOHaq6Ofc_uwZaW.png
수많은 LLM 중 무엇을 써야 할지 고민하는 시간을 줄여드립니다.

- **최신 모델 트래킹:** 새롭게 등장하는 LLM 모델을 실시간으로 확인하고 비교할 수 있습니다.
- **다각도 벤치마크:** 사용자의 목적(코딩, 추론, 미디어 모달 등)에 맞는 최적의 모델을 찾을 수 있도록 벤치마크 데이터를 제공합니다. '직관'이 아닌 '지표'를 바탕으로 모델을 선택 할 수 있습니다.
